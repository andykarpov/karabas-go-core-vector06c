# Вектор-06Ц: память, порты, видео

Источник — RTL ядра Sorgelig (`upstream/vector06_mister`), перенесённое в `src/rtl/v06c/`. Что проверено в симуляции (`src/sim/run.sh`), отмечено **[sim]**.

## Такты

| Что | Значение |
|---|---|
| Клок ядра | 48 МГц (у Sorgelig 96) |
| Пиксели | 12 МГц (`ce_12mp` / `ce_12mn`, две половины) |
| ЦП | 3 МГц (`ce_f1` / `ce_f2` раз в 16 клоков), турбо 6 МГц (раз в 8, без ожиданий) |
| Цикл памяти | 4 такта ЦП = 64 клока; каждый машинный цикл ЦП растянут до 4 T: NOP 4, MOV r,r 8, INX 8, JMP 12, SHLD 20 **[sim: INX D / JMP = 20 T, 2991 за кадр]** |
| ВИ53 | 1,5 МГц на все три канала |
| Кадр | 768 × 312 пикселей 12 МГц = 64 мкс × 312 = 19,968 мс (50,08 Гц), 59904 T ЦП **[sim]** |

## Память

| Адрес SRAM (байт) | Что |
|---|---|
| 00000–0FFFF | основное ОЗУ 64 КБ; экран 8000–FFFF — 4 плоскости по 8 КБ (8000, A000, C000, E000) |
| 10000–4FFFF | квазидиск 256 КБ, 4 страницы по 64 КБ |
| 50000–57FFF | ПЗУ загрузчика (из `.kg` или FL), читается с 0000 пока `rom_enable` и `addr < rom_size` |

Экран копируется в блочную память (`v06c_vram`) при каждой записи в 8000–FFFF страницы 0: видео читает 4 плоскости за раз и не ждёт SRAM.

## Порты (`addr[7:0]`)

Адреса регистров у ВВ55 / ВИ53 / ВГ93 инвертированы (`~addr[1:0]`): младший порт группы — управляющий регистр.

| Порт | Что |
|---|---|
| 00 | ВВ55 №1: управляющее слово |
| 01 | ВВ55 №1, C: вых. бит 0 — лента / бипер; вход: бит 4 — лента, 5 — СС (Shift), 6 — УС (Ctrl), 7 — РУС/ЛАТ (Alt), активный 0 |
| 02 | ВВ55 №1, B: вых. биты 3–0 — цвет бордюра (индекс палитры), бит 4 — режим 512; вход — столбцы клавиатуры (активный 0) |
| 03 | ВВ55 №1, A: опрос строк клавиатуры и регистр вертикальной прокрутки (берётся в конце кадра) |
| 04–05 | регистр выбора джойстиков (как у Sorgelig) |
| 06 | джойстик «П» (чтение) |
| 07 | джойстик «ПУ» (чтение), covox (запись, через 2 с после старта программы) |
| 08–0B | ВИ53: 08 — управляющее слово, 09 — канал 2, 0A — канал 1, 0B — канал 0 |
| 0C–0F | запись палитры: значение B2 G3 R3 в индекс текущего пикселя (обычно бордюра); 0E / 0F — чтение джойстиков «С» |
| 10 | квазидиск: биты 1–0 — страница окна, 3–2 — страница стека, 4 — стек в квазидиск, 5 — окно A000–DFFF, 6 — + 8000–9FFF, 7 — + E000–FFFF |
| 14–15 | AY (Ф3) |
| 18–1B | ВГ93: 18 — данные, 19 — сектор, 1A — дорожка, 1B — команда / состояние (один контроллер на оба привода) **[sim]** |
| 1C | дисковод: бит 0 — привод A/B, бит 2 — сторона (инверсно) |

## Видео

- Видимая область: `hc` 0–511, `vc` 0–255 (строки памяти 255…0 со сдвигом прокрутки), вокруг бордюр. Гашение по горизонтали 563–723, синхро 597–653; по вертикали гашение 267–295, синхро 271–281.
- Прерывание RST 7 (`INTA` читает FF) по фронту `retrace`, строка 272 **[sim: раз в кадр]**.
- Цвет пикселя (256): `{8000, A000, C000, E000}` = биты индекса 3…0 **[sim: плоскость 8000 → индекс 8]**; в 512 точки чётные / нечётные берут по две плоскости.
- Палитра по сбросу — таблица Sorgelig (пункт OSD «сохранять палитру» — бэклог).

## Загрузчик (ПЗУ 2 КБ, `src/roms/boot.rom`, из `bios.mif` Sorgelig = `zagr512` vector06cc)

- `bios.mif` записан с диапазонами (`[a..b] : v;`): первая конвертация их пропустила (нули вместо
  палитры и адресов переходов — чёрный экран и диск не грузился). Теперь байт в байт как `zagr512.mi` vector06cc **[sim]**.
- Чистит ОЗУ циклом `STAX B` (64 КБ, ≈ 0,5 с); при нажатом УС (Ctrl) — только экран.
- Экран: «ВЕКТОР-06Ц», значок кассеты / дискеты, полосы загрузки **[sim]**. Ждёт ленту (опрос PC4) и диск.
- Диск: Restore, загрузочный сектор (1) в DFE0, контрольная сумма заголовка, затем `[DFE4]` секторов с 0080
  (5 на сторону, обе стороны, шаг на следующую дорожку), пишет `JMP 0100` в 0000 и ждёт БЛК+ВВОД (PC 00BD).
  БЛК+ВВОД = сброс с выключенным ПЗУ (OSD «Start», Alt+F11) → МикроДОС 3.1, `A>` **[sim: ryba.fdd]**.
- Монтирование образа на A при включённом ПЗУ перезапускает Загрузчик (как у Sorgelig).
- Сброс клавишами (как у Sorgelig): F11 с Ctrl / Shift — в Загрузчик, Alt+F11 — в программу (ПЗУ выключено).
