# План ядра Вектор-06Ц для Karabas Go / Mini / Mini G

Цель: ядро ПК «Вектор-06Ц» (КР580ВМ80А 3 МГц, 64 КБ ОЗУ + квазидиск 256 КБ, графика 256 × 256 × 16 цветов из палитры 256 или 512 × 256 × 4, ВИ53, кадровое прерывание 50 Гц, дисковод КР1818ВГ93) для плат Karabas (XC6SLX25, ISE 14.7). Файлы идут через прошивку (OSD, `FL`, `F`, burst): загрузчика и soft-CPU в ядре нет. Железо и порты: `docs/HARDWARE.md` (Ф0). Открытые вопросы: `docs/BACKLOG.md`.

## Решения (пользователь 2026-11-21)

1. **Основа — ядро Sorgelig**, приведённое к нашим правилам: один клок с enable (у него 96 МГц и `negedge` для enable), память в SRAM вместо BRAM (`dpram` 384 КБ), `hps_io` / `ioctl` → `kg_mcu` (ROM loader, `FL`, `F`, HID, soft switches). Видео-тайминг HDMI и сверка поведения — по vector06cc. Импортированный код с пометкой `// karabas:` и кредитом.
2. **Видео: родной кадр Вектора на HDMI**, 576p (VIC 17/18) с 624 строками от клока машины, ≈ 50,08 Гц, удвоение строк без буфера кадра (как vector06cc). Строгий 625-строчный 576p не делаем. Проверить на мониторе пользователя и на захвате.
3. **ПЗУ «Загрузчик»** (2 КБ, `bios.v` / `zagr512.hex`) — в репо и в `.kg` (пользователь). Другое BOOT ROM — пунктом `FL` с карты из `/vector06c`.
4. **Репозиторий локальный**, на GitHub публичный к первому релизу (как CRISS). Ядро GPL v3.
5. **Опции в плане** (пользователь): AY (порты 14 / 15), лента `.cas` / `.wav`, Z80 вместо 8080 (пункт OSD), физический дисковод Go.
6. **Порядок плат:** сначала Mini G, Go и Mini в фазе релиза. Id ядра `vector06c`, файл `vector06c.kg`, каталог SD `/vector06c`.
7. **Дисковод — наш** `wd1793` + кэш образа в SRAM (как orion128 / specialist): `.fdd` Вектора = 80 дорожек × 2 стороны × 5 секторов × 1024 байт = 819200, тот же формат, что `.odi`. Проверить в Ф2 против `wd1793.sv` Sorgelig.

## Архитектура (черновик, уточняется в Ф0)

```
              ┌── CPU vm80a (ce 3 / 6 МГц) | T80 (Ф4)
 v06c_system  ├── ОЗУ 64 К + квазидиск 4 × 64 К (порт 10h) + ПЗУ — в SRAM
              ├── видео: 4 плоскости 8000–FFFF, палитра 16 × 8 бит (порт 0Ch), бордюр, скролл, 256 / 512
              ├── ВВ55 клавиатуры (00–03), ВВ55 польз. (04–07), ВИ53 (08–0B), AY (14 / 15), ВГ93 (18–1C)
              ├── кадровое прерывание RST7 50 Гц
              └── звук: ВИ53 × 3 + бипер + лента + AY → PCM
 kg_mcu ────── ROM loader (Загрузчик), FL (.rom / .edd / BOOT ROM), F (.fdd A / B), HID, переключатели
 верх платы ── PLL, удвоитель строк → HDMI 576p / 624 строки, kg_osd_overlay, kg_pcm5102
```

Клок: кратный 12 МГц (пиксели 12 МГц, CPU 3 МГц, HDMI 24 МГц × 5). Выбор (48 или 96 МГц) и раскладка слотов SRAM — Ф0.

## Фазы

Одна ветка на фазу, один PR в конце (локальный master до публикации).

### Ф0. Импорт и симуляция
- `tools/fetch_upstream.sh`, перенос RTL Sorgelig в `src/rtl/v06c/`, `docs/HARDWARE.md` (карта портов, биты ВВ55, видео) по исходникам.
- Синхронный `v06c_system`: клок, enable без `negedge`, ОЗУ / квазидиск / ПЗУ через SRAM-обёртку (от `spec_sram`), загрузчик ROM.
- Verilator: Загрузчик выходит на свой экран (кадр в PNG), `.rom` с 0100h стартует; сверка числа тактов между прерываниями с vector06cc / эмулятором.
- `make v06c-xst`: размер машины, без защёлок.

**Итог Ф0 (2026-11-21):** `src/rtl/v06c/` (v06c_system, _sram из specialist, _loader, _vram — копия экрана в BRAM 4 × 8 КБ, _video, _kbd; k580vv55 / k580vi53 Sorgelig; vm80a из specialist). Клок 48 МГц. `src/sim/run.sh` (~77 с): Загрузчик (с УС: чистит только экран, палитра чёрная, ждёт ленту), прерывание раз в кадр, `.rom` из FL 1 с 0100, 3 / 6 МГц одинаковый экран, такты: INX D / JMP = 2991 за кадр (циклы по 4 T). XST машины: 2817 LUT (18 %), 1260 FF, 16 RAMB16, 92 МГц.

### Ф1. Вектор на Mini G
- Верх Mini G (из specialist / orion128), удвоитель строк, HDMI 624 строки + звук, PS/2 / USB клавиатура → матрица 8 × 8 + УС / СС / РУС, OSD: Reset (Загрузчик / в программу), CPU 3 / 6 МГц, сброс палитры.
- `FL` `.rom` (автостарт), `.kg` с Загрузчиком. Проверка на плате и на захвате (после «да» на захват).

**Итог Ф1 (2026-11-21):** верх Mini G (DCM 50→48 МГц + PLL 48 / 24 / 120 / 8), `v06c_scan2x` — 576p родного кадра (768 × 624 при 24 МГц, активно 640 × 576), OSD, FL `.rom`. На Mini G (26112102–03): HDMI принят захватом, Загрузчик, клавиатура, `.rom` (Timersound svofski), звук ВИ53 по HDMI и ЦАП (пользователь: «звук норм» после исправления знака: микс Sorgelig беззнаковый, ЦАП / HDMI ждут дополнительный код — центрирован на 0, ±12272).

### Ф2. Квазидиск и дисковод
- Квазидиск 256 КБ (порт 10h), `FL` `.edd` (загрузка дампа).
- `wd1793` + кэш, `F` Disk A / B (`.fdd`, чтение / запись). МикроДОС с образа.

**Итог Ф2 (2026-11-21):** один ВГ93 на оба привода (как в Векторе), `v06c_fdd_cache` A 060000 / B 12D000, F 4 / 5; монтирование A при включённом ПЗУ — в Загрузчик. Найдено: (1) `bios.mif` с диапазонами `[a..b]` — первая конвертация дала нули (палитра Загрузчика, адреса переходов); теперь = `zagr512` vector06cc; (2) `v06c_sram`: при работе кэша чтение ЦП шло до 9 клоков и ЦП брал старый байт — теперь слоты сначала машине. Sim: квазидиск (FL `.edd`, окно порта 10), запись сектора на пустой образ, МикроДОС 3.1 с `ryba.fdd` до `A>`. Mini G 26112102: МикроДОС загрузилась, клавиатура в ней.

### Ф3. Звук и джойстики
- AY (jt49, порты 14 / 15), стерео-микс как у Sorgelig.
- Джойстики П / ПУ / С от USB-геймпадов (пункт OSD).

### Ф4. Опции
- Z80 (T80) — пункт OSD (как Специалист).
- Лента: вход с линии платы + воспроизведение `.cas` / `.wav` файлом (способ — в Ф4, по примеру tape monitor в tsconf / profi).
- Физический дисковод Go (от `spec_fdd_phys`).

### Ф5. Go, Mini и релиз
- Верхи Go / Mini, сборка трёх плат, `vector06c.kg` (build `YYMMDDNN`), README.md + README.ru.md (подробно: что где, форматы, где брать ПО).
- Репо публичным (спросить), строка в `cores.json` karabas-go + Sources в README.
