# Бэклог Вектор-06Ц

## Открытые вопросы
- Клок системы: 48 или 96 МГц (Ф0), слоты SRAM для CPU / видео (4 плоскости за такт видео) / загрузчика / кэша FDD.
- Строгий 576p50 с буфером кадра — только если монитор / захват не примут 624 строки.
- Лента: формат `.cas` (какой именно у эмуляторов Вектора) и `.wav` — способ в Ф4.
- Тестовое ПО: свои `.rom` демо svofski (v06c-*), МикроДОС `.fdd` — где взять, что можно класть на карту.

## Проверить
- `.fdd` = `.odi` (80 × 2 × 5 × 1024): сверить с `wd1793.sv` Sorgelig.

## Перенесено из плана (пользователь 2026-11-21)
- Z80 вместо 8080 (пункт OSD; у Sorgelig — экспериментальный).
- Лента `.cas` (формат эмуляторов) — сейчас только `.wav` и вход платы.
- Физический дисковод Go (от `spec_fdd_phys`).
- Пункт OSD «сохранять / не сохранять» образы дисков; Go / Mini проверить на плате.
