# Vector-06C core for Karabas Go / Mini / Mini G

Work in progress. A core of the Soviet home computer Vector-06C for the Karabas boards (Spartan-6 XC6SLX25).

Based on the MiSTer Vector-06C core by Sorgelig and on vector06cc by Viacheslav Slavinsky (svofski); KR580VM80A model by Vslav (1801BM1). See `docs/PLAN.md` (in Russian).
